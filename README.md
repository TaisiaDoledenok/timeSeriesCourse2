## Задача №1. Исследовательский анализ (EDA)

1. Загрузка и первичный анализ данных
Датасет содержит почасовые данные о количестве автомобилей на 4 перекрёстках за период с ноября 2015 по июнь 2017. Пропусков нет, шаг временного ряда регулярный (почасовой). Удалила неинформативный столбец ID. Установлен индекс datetime (из соответствующей колонки). Для трех перекрестков есть информация на 608 дней, для четвёртого — 181 день. Данные не содержат дубликаты и пропуски.

2. Анализ предметной задачи
Горизонт прогнозирования - 5 часов. Шаг прогноза - 1 час (соответствует частоте данных). Этого достаточно, чтобы организовать дорожное движение с учетом возможных пробок. Режим обучения: оффлайн, так как есть только исторические данные о перекрестках. 
Метрики: В качестве основной метрики качества выбрана RMSE. Она квадратично штрафует крупные отклонения, что заставляет модель точнее отражать пиковые нагрузки и выбросы, важные для управления трафиком. Для интерпретации выбрана MAE (показывает среднюю ошибку в машинах в час). При этом МАЕ устойчива к выбросам.

## Задача №2. Статистические методы для предсказания временных рядов

Обоснование выбора
Для прогнозирования были использованы модели их из библиотеки statsforecast:
Наивные модели (Naive, SeasonalNaive)
Классические статистические модели: ARIMA, AutoARIMA, ETS, Theta, AutoTheta, HoltWinters.
Для выбранных временных рядов (трафик дорожного движения) ключевыми являются суточная и недельная сезонность. Также отмечено влияние выходных/праздников на трафик (снижение интенсивности). 

Оценка моделей
Наилучшую точность показала модель ETS (RMSE ≈ 5.51, MSE ≈ 40.23), что указывает на эффективность адаптивного экспоненциального сглаживания для данных с трендом и сезонностью.
Методы Holt-Winters и Theta также дали хорошие результаты, немного уступая ETS.
AutoARIMA и ARIMA(1,1,1) оказались сопоставимы, но менее точны, чем сезонные экспоненциальные модели.
Наивные методы показали наибольшие ошибки, что подтверждает наличие выраженной сезонной структуры, которую простые подходы не учитывают.
Подытожим, данные хорошо предсказуемы с использованием методов, основанных на адаптивном экспоненциальном сглаживании. Для повышения точности требуется учет дополнительных факторов и применение бектестинга и анализа остатков. Бектестинг нужен для оценки стабильности на разных периодах (например, будние и выходные), а анализ остатков позволяет выявить неучтенные паттерны (например, праздничные эффекты).

## Задача №3. Методы МЛ и DL  для предсказания

Обоснование выбора

На основе EDA можно выделить ключевые особенности данных, которые делают использование ансамблевых деревьев решений оправданным:
Сложная нелинейная зависимость так как трафик зависит от множества факторов (время суток, день недели, месяц, праздники, погодные условия и т.д.). Деревья хорошо работают с такими данными. В MLForecast использованы лаги (1,2,3,24,168) и календарные признаки (hour, dayofweek, month). еревья автоматически ранжируют важность этих признаков и строят правила, учитывающие их совместное влияние. LightGBM и RandomForest устойчивы к аномалиям (которые есть на перекрёстках 3 и 4).
Модели представляют разные подходы внутри семейства деревьев:
RandomForest – бэггинг, снижает дисперсию.
XGBoost и LightGBM – градиентный бустинг, последовательно исправляют ошибки.

## Заключение

В ходе работы выполнен полный цикл анализа и прогнозирования почасового трафика на четырех перекрестках (данные с ноября 2015 по июнь 2017). По результатам исследовательского анализа установлены значительные различия в уровнях загрузки, трендах и сезонности, что потребовало индивидуального подбора моделей для каждого перекрестка.

Были опробованы статистические методы (Naive, SeasonalNaive,ARIMA(1,1,1), ETS, Holt‑Winters и Theta  ), ансамблевые деревья (RandomForest, XGBoost, LightGBM) и нейросетевые модели NHITS, NBEATS и TFT. Установлено, что оптимальный для прогнозирования горизонт до 5 часов (шаг — 1 час) в зависимости от перекрестка. 

В качестве основной метрики качества использована RMSE, дополнительно — MSE.

- Для перекрестка 1 наилучшей моделью оказалась ETS (экспоненциальное сглаживание) с RMSE = 3.145 и MSE = 9.890. Горизонт прогнозирования составляет 5 часов. Модель обеспечивает высокую точность благодаря учету тренда и сезонности, характерных для этого загруженного перекрёстка.
- На перекрестке 2 лучший результат показала нейросетевая модель NHITS с минимальными ошибками: RMSE = 1.341, MSE = 1.799 при горизонте 5 часов. Это наилучшая точность среди всех перекрестков, что объясняется более стабильным и предсказуемым трафиком на данном участке.
- Для перекрестка 3 снова выбрана ETS (RMSE = 7.917, MSE = 62.679), но горизонт сокращен до 4 часов. Здесь ошибки заметно выше, что связано с наличием выбросов и отсутствием устойчивого тренда, усложняющих прогнозирование.
- На перекрестке 4 применена модель ARIMA(1,1,1) с RMSE = 7.324 и MSE = 53.635 при горизонте всего 1 час. Это решение обусловлено стационарностью ряда и меньшей волатильностью, однако ошибка остаётся значительной, что требует дальнейшего улучшения модели.

Построенный пайплайн показал свою работоспособность и может быть использован для оперативного прогнозирования загрузки перекрестков.
